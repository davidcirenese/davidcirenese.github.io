YourSay - Civic Engagement Platform

I built YourSay, a platform that helps citizens stay informed about upcoming legislation and share their opinions on bills at all levels - from local town halls to state legislatures and federal congress. The platform fetches real-time legislative data, allows users to vote on bills and submit detailed opinions, and uses AI-powered summaries to help users understand complex legislation at a glance.

David's Musical Machine

An interactive C++ animation software that visualizes mechanical machines designed to produce music. Users can switch between different machine configurations and trigger musical instruments by striking them. The project heavily demonstrates object-oriented programming principles with multiple components like motors, pulleys, pegs, and instruments all working together in a coordinated animation timeline.

Vehicle Simulator
